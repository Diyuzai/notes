00写在前面

01直觉与统一框架

把问题想象成走迷宫：

DFS

一条路走到黑

沿着一条边一直走，撞墙就退回上一个岔路口，换一条没走过的路。对应栈 / 递归。

LIFO · 后进先出
BFS

水波纹扩散

先把距离为 1 的点全部访问完，再访问距离为 2 的点。对应队列。

FIFO · 先进先出

两者共享同一个骨架：边界集 frontier 存放“发现了但还没扩展”的点，已访问集 visited 防止重复和死循环。DFS 从边界集的末尾取点，BFS 从开头取点。

统一框架 · C++ 伪代码 
// 统一框架：DFS 与 BFS 只差一个“取点”的位置
void search(int start) {
    deque<int> frontier{start};
    vector<char> visited(n + 1, 0);
    visited[start] = 1;

    while (!frontier.empty()) {
        int u;
        if (use_dfs) {                 // DFS：后进先出
            u = frontier.back();
            frontier.pop_back();
        } else {                       // BFS：先进先出
            u = frontier.front();
            frontier.pop_front();
        }

        for (int v : g[u]) {
            if (!visited[v]) {
                visited[v] = 1;
                frontier.push_back(v);
            }
        }
    }
}

搜索问题的三要素

要素含义例子
状态搜索树上的一个节点，必须能唯一标识迷宫坐标、八数码局面、转盘锁的四位数字
转移从一个状态走一步到另一个状态上下左右走、拨动一位、交换两个数字
判重避免重复访问同一个状态visited 数组、unordered_set
复杂度 邻接表下 DFS/BFS 都是 O(V+E)；网格图是 O(nm)。每个点最多进队/入栈一次，每条边最多被扫描两次（无向图）。

02前置：图的 C++ 存储

写搜索之前，先把图存好。C++ 最常用的是 vector<vector<int>> 邻接表：时间 O(V+E)，空间 O(V+E)，写起来也最直观。

<bits/stdc++.h> 不是标准头文件 它是 GCC 的“万能头”，竞赛里常用，但 MSVC 和部分环境不认识。跨平台时请分别包含 <vector>、<queue>、<iostream> 等标准头。

邻接表（首选）

graph.cpp · 邻接表 
int n, m;
cin >> n >> m;

for (int i = 0; i < m; ++i) {
    int u, v;
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);   // 无向图；有向图删掉这一行
}

// 遍历 u 的所有邻居
for (int v : g[u]) {
    // ...
}

无向图要加两条有向边；有向图只加 g[u].push_back(v)。g[u].size() 就是 u 的度。

03DFS：深度优先搜索

DFS 沿着一条边一直走，能走多远走多远；走不通时回溯到上一个分叉点，换一条没走过的边。递归写法天然就是 DFS，因为函数调用栈就是“栈”。

基础模板

dfs.cpp · 基础模板 
vector<vector<int>> g;
vector<char> vis;

void dfs(int u) {
    vis[u] = 1;

    // 进入 u：先序
    for (int v : g[u]) {
        if (!vis[v]) {
            dfs(v);
        }
    }
    // 离开 u：后序
}

三个关键点：进入时标记、只递归未访问的邻居、离开时按需处理。如果是计数所有路径，还要在离开时撤销标记。

遍历整张图（处理不连通）

dfs.cpp · 连通块 
int components = 0;

for (int i = 1; i <= n; ++i) {
    if (!vis[i]) {
        ++components;
        dfs(i);
    }
}
只从一个点 DFS 会漏连通块 图不一定连通，外层必须循环所有未访问点。每进入一次 DFS，就是一个新的连通块。

时间戳与 DFS 序

dfn[u] 是进入时间，tout[u] 是离开时间，sz[u] 是子树大小。子树 u 在 dfn 上是连续区间 [dfn[u], tout[u]]，这是树状数组/线段树维护子树信息、求 LCA 的基础。

dfs.cpp · 时间戳 
int timer = 0;
vector<int> dfn(n + 1), tout(n + 1), sz(n + 1);

void dfs(int u) {
    dfn[u] = ++timer;
    sz[u] = 1;

    for (int v : g[u]) {
        if (!dfn[v]) {
            dfs(v);
            sz[u] += sz[v];
        }
    }
    tout[u] = timer;
}

判环

有向图：三色标记

0 表示未访问，1 表示在递归栈中，2 表示已完成。遇到颜色 1 说明找到了回边，有环。

cycle.cpp · 有向图三色 
vector<int> color(n + 1, 0);   // 0 未访问，1 在栈中，2 已完成

bool dfs(int u) {
    color[u] = 1;

    for (int v : g[u]) {
        if (color[v] == 1) return true;          // 回边：有环
        if (color[v] == 0 && dfs(v)) return true;
    }

    color[u] = 2;
    return false;
}

bool hasCycle() {
    for (int i = 1; i <= n; ++i) {
        if (color[i] == 0 && dfs(i)) return true;
    }
    return false;
}

无向图：父节点判断

遇到已访问且不是父节点的点，说明有环。

cycle.cpp · 无向图父节点 
bool dfs(int u, int parent) {
    vis[u] = 1;

    for (int v : g[u]) {
        if (v == parent) continue;   // 回到父节点不算环
        if (vis[v]) return true;     // 访问到已访问的祖先：有环
        if (dfs(v, u)) return true;
    }
    return false;
}
重边和自环 有重边时 v == parent 会误判，需要记录边的编号；有自环时直接就是环。有向图不能套用无向图的父节点法，必须用三色标记。

拓扑排序（DFS 后序逆序）

边 u → v 表示 u 必须在 v 前面。后序中 v 先完成，逆序后 u 就在 v 前面。只适用于 DAG；有环时这个顺序不合法。

topo.cpp · DFS 后序 
vector<int> order;

void dfs(int u) {
    vis[u] = 1;

    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }

    order.push_back(u);   // 后序
}

for (int i = 1; i <= n; ++i) {
    if (!vis[i]) dfs(i);
}
reverse(order.begin(), order.end());

二分图染色

相邻点染不同颜色。图可能不连通，外层要循环所有点。

bipartite.cpp · 染色 
vector<int> color(n + 1, -1);

bool dfs(int u, int c) {
    color[u] = c;

    for (int v : g[u]) {
        if (color[v] == -1) {
            if (!dfs(v, c ^ 1)) return false;
        } else if (color[v] == c) {
            return false;
        }
    }
    return true;
}

bool isBipartite() {
    for (int i = 1; i <= n; ++i) {
        if (color[i] == -1 && !dfs(i, 0)) return false;
    }
    return true;
}

树的直径

任取一点 BFS 到最远点 a，再从 a BFS 到最远点 b，dist(a,b) 就是直径。只适用于无权树；带权树要用树形 DP。

tree.cpp · 树的直径 
pair<int, int> farthest(int s) {
    vector<int> dist(n + 1, -1);
    queue<int> q;

    dist[s] = 0;
    q.push(s);

    int best = s;
    while (!q.empty()) {
        int u = q.front();
        q.pop();

        if (dist[u] > dist[best]) best = u;

        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return {best, dist[best]};
}

int treeDiameter() {
    auto [a, d1] = farthest(1);
    auto [b, d2] = farthest(a);
    return d2;
}

回溯：DFS 最重要的变体

回溯 = DFS + 撤销选择。它是排列、组合、子集、N 皇后、数独、单词搜索的基础。

回溯模板 · 伪代码 
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        结果.push_back(路径);
        return;
    }

    for (选择 : 选择列表) {
        if (不合法) continue;

        做选择;
        backtrack(路径, 新的选择列表);
        撤销选择;
    }
}

全排列

permute.cpp · 全排列 
vector<vector<int>> permute(vector<int>& nums) {
    int n = nums.size();
    vector<vector<int>> res;
    vector<int> path;
    vector<char> used(n, 0);

    function<void()> dfs = [&]() {
        if ((int)path.size() == n) {
            res.push_back(path);
            return;
        }

        for (int i = 0; i < n; ++i) {
            if (used[i]) continue;

            used[i] = 1;
            path.push_back(nums[i]);

            dfs();

            path.pop_back();
            used[i] = 0;
        }
    };

    dfs();
    return res;
}

N 皇后

用三个数组分别记录列、主对角线 r-c、副对角线 r+c，实现 O(1) 冲突判断。

n_queens.cpp · N 皇后 
int n;
vector<int> col, diag1, diag2, path;
vector<vector<int>> ans;

void dfs(int r) {
    if (r == n) {
        ans.push_back(path);
        return;
    }

    for (int c = 0; c < n; ++c) {
        if (col[c] || diag1[r - c + n] || diag2[r + c]) continue;

        col[c] = diag1[r - c + n] = diag2[r + c] = 1;
        path.push_back(c);

        dfs(r + 1);

        path.pop_back();
        col[c] = diag1[r - c + n] = diag2[r + c] = 0;
    }
}

int main() {
    cin >> n;

    col.assign(n, 0);
    diag1.assign(2 * n + 1, 0);
    diag2.assign(2 * n + 1, 0);

    dfs(0);
    cout << ans.size() << '\n';
}

剪枝与迭代加深

DFS 枚举所有方案时，不加剪枝通常是指数级。常见剪枝：

  • 可行性剪枝：当前状态已经不可能合法，直接返回。
  • 最优性剪枝：当前代价 ≥ 已知最优，直接返回。
  • 搜索顺序优化：先试分支少、成功率高的情况。
  • 记忆化：相同状态只算一次。
  • 上下界剪枝：估计剩余部分的最好/最坏情况。

当答案深度未知、BFS 内存又太大时，可以用迭代加深：限制深度做 DFS，没找到就增加深度再来一遍。

iddfs.cpp · 迭代加深 
bool dfs(int u, int depth, int limit) {
    if (depth > limit) return false;
    if (u == target) return true;

    for (int v : g[u]) {
        if (dfs(v, depth + 1, limit)) return true;
    }
    return false;
}

for (int limit = 0; ; ++limit) {
    if (dfs(start, 0, limit)) break;
}

递归爆栈与显式栈

C++ 递归深度受栈大小限制：Windows 默认约 1 MB，Linux 约 8 MB。深图（例如 10⁶ 个点的链）必须用 BFS 或显式栈。

dfs.cpp · 显式栈 
vector<int> st;
st.push_back(s);
vis[s] = 1;

while (!st.empty()) {
    int u = st.back();
    st.pop_back();

    for (int v : g[u]) {
        if (!vis[v]) {
            vis[v] = 1;
            st.push_back(v);
        }
    }
}
不要依赖加大栈 本地可以用 -Wl,--stack=268435456 加大 Windows 栈，Linux 可以用 ulimit -s unlimited，但评测机环境固定，正确做法是改写成 BFS 或显式栈。

04BFS：广度优先搜索

BFS 从起点开始，先把距离为 1 的点全部访问完，再访问距离为 2 的点。队列保证先进先出，从而按层扩展。

为什么 BFS 能求无权图最短路 队列先进先出，先入队的点距离更小；BFS 按距离非递减顺序扩展；一个点第一次被访问时，一定是从最短路径到达的。所以 dist[v] = dist[u] + 1 第一次赋值就是最短距离。

基础模板

bfs.cpp · 基础模板 
vector<int> bfs(int s) {
    vector<int> dist(n + 1, -1);
    queue<int> q;

    dist[s] = 0;
    q.push(s);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}
入队时标记，不是出队时标记 如果在出队时才标记 visited，同一个点可能被重复入队，队列会爆炸。BFS 必须在 dist[v] == -1 成立、准备入队时就标记。

网格 BFS

bfs.cpp · 网格最短路 
int n, m;
vector<string> grid;
vector<vector<int>> dist;

int bfs(int sx, int sy, int tx, int ty) {
    dist.assign(n, vector<int>(m, -1));
    queue<pair<int, int>> q;

    dist[sx][sy] = 0;
    q.push({sx, sy});

    const int dx[4] = {1, -1, 0, 0};
    const int dy[4] = {0, 0, 1, -1};

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        if (x == tx && y == ty) return dist[x][y];

        for (int d = 0; d < 4; ++d) {
            int nx = x + dx[d];
            int ny = y + dy[d];

            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (grid[nx][ny] == '#' || dist[nx][ny] != -1) continue;

            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    return -1;
}

分层 BFS

题目要按层处理时（二叉树层序、每秒扩散），先存下当前层的数量 sz，再循环 sz 次。

bfs.cpp · 分层 
int level = 0;

while (!q.empty()) {
    int sz = (int)q.size();   // 先存当前层大小
    while (sz--) {
        auto [x, y] = q.front();
        q.pop();
        // 处理当前层
    }
    ++level;
}

多源 BFS

把所有源点一开始都入队，距离设为 0。求的是每个点到最近源点的距离，典型题：腐烂的橘子、01 矩阵。

bfs.cpp · 多源 
queue<pair<int, int>> q;
vector<vector<int>> dist(n, vector<int>(m, -1));

for (auto [x, y] : sources) {
    dist[x][y] = 0;
    q.push({x, y});
}

0-1 BFS

边权只有 0 和 1 时，用双端队列：边权 0 放队首，边权 1 放队尾。复杂度仍然是 O(V+E)。

bfs.cpp · 0-1 BFS 
vector<int> dist(n + 1, INT_MAX);
deque<int> dq;

dist[s] = 0;
dq.push_back(s);

while (!dq.empty()) {
    int u = dq.front();
    dq.pop_front();

    for (auto [v, w] : g[u]) {   // w 只能是 0 或 1
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            if (w == 0) dq.push_front(v);
            else        dq.push_back(v);
        }
    }
}
进阶：双向 BFS（状态图很大时）

从起点和终点同时 BFS，每次扩展较小的一侧，两边相遇时距离相加。复杂度从 O(bd) 降到大约 O(bd/2)。

bfs.cpp · 双向 BFS 
int bibfs(int s, int t) {
    if (s == t) return 0;

    unordered_map<int, int> d1, d2;
    queue<int> q1, q2;

    d1[s] = 0; q1.push(s);
    d2[t] = 0; q2.push(t);

    while (!q1.empty() && !q2.empty()) {
        if (q1.size() > q2.size()) {
            swap(q1, q2);
            swap(d1, d2);
        }

        int sz = (int)q1.size();
        while (sz--) {
            int u = q1.front(); q1.pop();

            for (int v : next_states(u)) {
                if (d1.count(v)) continue;

                d1[v] = d1[u] + 1;
                if (d2.count(v)) return d1[v] + d2[v];
                q1.push(v);
            }
        }
    }
    return -1;
}
进阶：优先队列 BFS（Dijkstra）

边权不是 1 时，普通 BFS 失效。把队列换成小根堆，每次取当前距离最小的点扩展，就是 Dijkstra。

dijkstra.cpp · 优先队列 
vector<long long> dist(n + 1, LLONG_MAX);
priority_queue<pair<long long, int>,
               vector<pair<long long, int>>,
               greater<>> pq;

dist[s] = 0;
pq.push({0, s});

while (!pq.empty()) {
    auto [d, u] = pq.top();
    pq.pop();

    if (d != dist[u]) continue;   // 过期状态

    for (auto [v, w] : g[u]) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
    }
}

状态编码与哈希

  • 网格坐标：x * m + y 压成一个整数。
  • 多维状态：混合进制编码，例如 (a,b,c) → a*B1*B2 + b*B2 + c。
  • 字符串：直接用 string，配 unordered_set<string>。
  • 排列：康托展开，或 next_permutation 枚举。
  • pair：unordered_set<pair<int,int>> 不能直接用，需要自定义哈希。

维度DFSBFS

怎么选

A最少步数 / 最少操作优先 BFS，尤其是无权图或网格。
B所有方案 / 方案数优先 DFS + 回溯，记得撤销选择。
C连通块 / 判环 / 拓扑 / 二分图DFS、BFS 都能做，看哪个好写。
D图很深不要递归 DFS，用 BFS 或显式栈。
E边权 0 / 1用双端队列的 0-1 BFS。
F边权任意非负优先队列 BFS，也就是 Dijkstra。

洛谷 P1443 马的遍历

BFS网格入门

题意：n×m 的棋盘，马从 (x,y) 出发，求到每个点的最少步数，走不到输出 -1。

思路：马走日，8 个方向；无权图最短路，直接 BFS。每个点第一次被访问时的距离就是答案，dist != -1 兼作 visited。

P1443.cpp · 完整程序 
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, sx, sy;
    cin >> n >> m >> sx >> sy;
    --sx; --sy;   // 输入是 1-indexed

    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int, int>> q;

    dist[sx][sy] = 0;
    q.push({sx, sy});

    const int dx[8] = {2, 2, 1, 1, -1, -1, -2, -2};
    const int dy[8] = {1, -1, 2, -2, 2, -2, 1, -1};

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        for (int d = 0; d < 8; ++d) {
            int nx = x + dx[d];
            int ny = y + dy[d];

            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (dist[nx][ny] != -1) continue;

            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            cout << left << setw(5) << dist[i][j];
        }
        cout << '\n';
    }
    return 0;
}

时间 O(nm)，空间 O(nm)。

02

洛谷 P1605 迷宫

DFS回溯计数

题意：n×m 迷宫，有 t 个障碍，求从起点到终点、每个格子最多走一次的路径数。

思路：DFS 枚举所有路径；进入格子时标记，递归结束后撤销标记。计数问题不能像连通块那样标记后就不管。

P1605.cpp · 完整程序 
#include <bits/stdc++.h>
using namespace std;

const int N = 105;

int n, m, t, sx, sy, tx, ty;
bool blocked[N][N], vis[N][N];
int ans = 0;

const int dx[4] = {1, -1, 0, 0};
const int dy[4] = {0, 0, 1, -1};

void dfs(int x, int y) {
    if (x == tx && y == ty) {
        ++ans;
        return;
    }

    for (int d = 0; d < 4; ++d) {
        int nx = x + dx[d];
        int ny = y + dy[d];

        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (blocked[nx][ny] || vis[nx][ny]) continue;

        vis[nx][ny] = true;
        dfs(nx, ny);
        vis[nx][ny] = false;   // 回溯
    }
}

int main() {
    cin >> n >> m >> t >> sx >> sy >> tx >> ty;

    for (int i = 0; i < t; ++i) {
        int x, y;
        cin >> x >> y;
        blocked[x][y] = true;
    }

    vis[sx][sy] = true;
    dfs(sx, sy);

    cout << ans << '\n';
    return 0;
}

最坏情况指数级，但迷宫规模小，回溯足够。

LeetCode 200 岛屿数量

DFS连通块Flood Fill

题意：网格中 '1' 是陆地，'0' 是水，上下左右相连的陆地算一个岛，求岛屿数量。

思路：外层扫描每个格子，遇到未访问的 '1'，岛屿数 +1，然后 DFS 把整个岛改成 '0'。直接修改 grid 当 visited，省一个数组。

leetcode200.cpp 
class Solution {
public:
    int n, m;
    int dx[4] = {1, -1, 0, 0};
    int dy[4] = {0, 0, 1, -1};

    void dfs(vector<vector<char>>& grid, int x, int y) {
        if (x < 0 || x >= n || y < 0 || y >= m || grid[x][y] != '1') return;

        grid[x][y] = '0';   // 标记已访问
        for (int d = 0; d < 4; ++d) {
            dfs(grid, x + dx[d], y + dy[d]);
        }
    }

    int numIslands(vector<vector<char>>& grid) {
        if (grid.empty()) return 0;

        n = grid.size();
        m = grid[0].size();
        int cnt = 0;

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (grid[i][j] == '1') {
                    ++cnt;
                    dfs(grid, i, j);
                }
            }
        }
        return cnt;
    }
};

时间 O(nm)，空间 O(nm)（递归栈最坏情况）。大网格建议改 BFS。

LeetCode 207 课程表

拓扑排序Kahn判环

题意：n 门课，先修关系 [a,b] 表示学 a 之前必须先学 b，判断能否修完所有课。

思路：判断有向图有没有环。Kahn 算法：入度为 0 的点入队，依次删除；最后输出点数等于 n 则无环。

leetcode207.cpp 
bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> g(numCourses);
    vector<int> indeg(numCourses, 0);

    for (auto& p : prerequisites) {
        int a = p[0], b = p[1];   // b -> a
        g[b].push_back(a);
        ++indeg[a];
    }

    queue<int> q;
    for (int i = 0; i < numCourses; ++i) {
        if (indeg[i] == 0) q.push(i);
    }

    int cnt = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ++cnt;

        for (int v : g[u]) {
            if (--indeg[v] == 0) q.push(v);
        }
    }

    return cnt == numCourses;
}

时间 O(V+E)，空间 O(V+E)。

LeetCode 752 打开转盘锁

BFS状态空间隐式图

题意：四位密码锁，每次把某一位 +1 或 -1（9 变 0，0 变 9），有一些死亡数字不能出现，求从 0000 到目标的最少步数。

思路：每个四位数是一个状态，一次拨动是一条边，就是无权图最短路。BFS 动态生成邻居，不需要提前建图。

leetcode752.cpp 
int openLock(vector<string>& deadends, string target) {
    unordered_set<string> dead(deadends.begin(), deadends.end());
    if (dead.count("0000")) return -1;

    queue<pair<string, int>> q;
    unordered_set<string> seen{"0000"};
    q.push({"0000", 0});

    while (!q.empty()) {
        auto [state, d] = q.front();
        q.pop();

        if (state == target) return d;

        for (int i = 0; i < 4; ++i) {
            for (int delta : {1, -1}) {
                string nxt = state;
                int digit = (nxt[i] - '0' + delta + 10) % 10;
                nxt[i] = char('0' + digit);

                if (!seen.count(nxt) && !dead.count(nxt)) {
                    seen.insert(nxt);
                    q.push({nxt, d + 1});
                }
            }
        }
    }
    return -1;
}

状态数最多 10⁴，BFS 足够；状态更多时考虑双向 BFS。

07易错点清单

下面这些坑，90% 的 WA/RE 都来自其中。

数组与初始化

  1. 大数组放局部：int vis[10000000]; 放函数里会爆栈。放全局或 static，或者用 vector。
  2. memset 不是万能的：只适合按字节赋 0、-1、0x3f；其他值用 fill。
  3. vector<bool> 是特化：v[i] 返回代理对象，别用它存 visited，用 vector<char>。
  4. 多组数据不清空：g.assign(n+1,{})、vis.assign(...)、memset(head,-1,...)。
  5. 二维数组初始化：vector<vector<int>> dist(n, vector<int>(m, -1));，不要写成一维。

DFS

  1. 递归深度：C++ 也会爆栈，深图用 BFS/显式栈。
  2. 回溯不撤销：计数路径时，递归返回后必须恢复 vis 和路径。
  3. 有向图判环用错方法：不能套无向图的父节点法，要用三色标记。
  4. 无向图重边/自环：重边会让 v == parent 误判，需要记录边编号。
  5. 递归函数里改全局变量：注意作用域，必要时用引用参数。

BFS

  1. 出队才标记：同一个点会重复入队，队列爆炸。要在入队时标记。
  2. q.size() 是无符号数：循环中队列会变长，先存 int sz = q.size()。
  3. 边权不为 1 还用普通 BFS：0/1 用 0-1 BFS，任意非负用 Dijkstra。
  4. 多源 BFS 漏源点：所有源点一开始都要入队，距离设 0。
  5. 队列内存：状态多时 BFS 的 frontier 可能很大，考虑双向 BFS 或剪枝。

C++ / STL

  1. 范围 for 的 auto 会拷贝：大对象用 const auto& 或 auto&。
  2. endl 会刷新缓冲区：大量输出用 '\n'。
  3. INT_MAX 加法溢出：dist[u] + w 可能溢出，用 long long 或先判断。
  4. priority_queue 默认大根堆：小根堆要写 greater<>。
  5. queue 没有 clear()：重新声明，或 q = {};。
  6. unordered_map 可能被卡：竞赛中有人构造哈希冲突，必要时自定义哈希或换 map。

10总结

  • DFS 用栈/递归，BFS 用队列；两者共享“边界集 + 已访问集”的骨架。
  • BFS 能求无权图最短路，关键是入队时标记；边权不为 1 时换 0-1 BFS 或 Dijkstra。
  • DFS 适合枚举方案、连通性、回溯、拓扑；BFS 适合最少步数、分层、多源。
  • 网格题记住方向数组，图论题记住外层循环处理不连通。
  • 模板要手敲，题要自己做；看懂 ≠ 会写，会写 ≠ 能调对。

    dist[s] = 0

网格 BFS（Python）
grid_bfs.py · 对话一原版 
from collections import deque

def bfs(grid, sx, sy, tx, ty):
    n, m = len(grid), len(grid[0])
    dist = [[-1] * m for _ in range(n)]
    dist[sx][sy] = 0
    q = deque([(sx, sy)])
    dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        x, y = q.popleft()
        if (x, y) == (tx, ty):
            return dist[x][y]

        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if (0 <= nx < n and 0 <= ny < m
                    and grid[nx][ny] != '#'
                    and dist[nx][ny] == -1):
                dist[nx][ny] = dist[x][y] + 1
                q.append((nx, ny))
    return -1
